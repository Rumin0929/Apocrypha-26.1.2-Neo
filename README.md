
About the mod
=======
This is a mod being developed,whose theme is adventure.
The latest version is 0.0.1-beta released on 2026.11.26.

Update Log(0.0.1-beta)
=======
- Silvery Armors
- 4 Tarot card have their own functions now ,besides I remake The Hierophant (Upright) 
- A new tarot card--The Wheel of Fortune (Reversed)
- A relic named **The Wafer** which comes from **The Binding of Issac**
- Adjust some of the loot tables of chests and villagers trades in original Minecraft
- Silver ore and Deepslate silver ore can be found in the world now
- A new structure---chapel,which has 5 types

Fixed
=====
- Fixed some of the bug that Sun's and Moon's accelerate priority can cross saves
